Enable Print Time Date Basic

Automatically stamp every PDF report with the exact date & time it was printed — system-wide, zero configuration.

Overview

Once installed, this module automatically appends a "Printed on: Month DD, YYYY HH:MM AM/PM (GMT)" line at the very bottom of every PDF or printed report in Odoo. No settings, no toggles, no per-model configuration — just install and every report footer gets the timestamp.

Key Features

  • Adds a clean print timestamp to the footer of every PDF / printed report system-wide.
  • Displays date and time in Month DD, YYYY HH:MM AM/PM (GMT) format.
  • Time is always expressed in GMT / UTC — unambiguous regardless of server or user time zone.
  • Covers all four built-in Odoo report layouts: Standard, Striped, Boxed, and Bold.
  • Compatible with both Odoo Community and Enterprise editions.
  • Zero configuration — install and it works immediately.
  • Lightweight — no new database tables, no Python models, no settings screens.

How It Works

  1. Install the module from the Apps menu.
  2. Print or export any report to PDF from anywhere in Odoo.
  3. The footer now shows: Printed on: May 24, 2025 02:15 PM (GMT)
  4. The timestamp is generated server-side at the exact moment of printing — always accurate.

Technically, the module uses standard Odoo QWeb template inheritance to inject a timestamp <div> into the footer of all four built-in layout templates (web.external_layout_standard, web.external_layout_striped, web.external_layout_boxed, web.external_layout_bold).

Technical Information

  • Compatible with Odoo 19.0
  • Editions: Community & Enterprise
  • Dependencies: web (no additional modules required)
