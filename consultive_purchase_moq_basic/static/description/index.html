Minimum Order Quantity per Vendor-Product

Enforce vendor-specific MOQ on Odoo Purchase Orders with on-the-fly warnings.

Overview

Out of the box, Odoo supports vendor pricelists with quantity breaks but does not enforce a true Minimum Order Quantity (MOQ) at Purchase Order creation. This lightweight module fills that gap by adding a dedicated MOQ field per vendor-product, and surfacing a clear warning when a buyer attempts to order below the configured minimum.

Key Features

  • Adds a dedicated MOQ field on each vendor row inside the product's Purchase tab.
  • Keeps Odoo's existing price-break logic (min_qty) fully intact — MOQ is a separate, non-interfering field.
  • Adds a read-only Vendor MOQ column on every Purchase Order line, auto-resolved from the selected vendor and product.
  • Shows an on-screen warning popup if the ordered quantity falls below the configured MOQ.
  • Non-blocking by design — buyers stay in control while being informed.
  • Works for both Requests for Quotation (RFQ) and confirmed Purchase Orders.

How It Works

  1. Open any product and navigate to the Purchase tab.
  2. In the vendor list, enter a value in the new MOQ column for each vendor row.
  3. When a buyer creates a Purchase Order or RFQ for that vendor, the MOQ is displayed alongside the quantity field.
  4. If the buyer enters a quantity below the MOQ, a warning popup is shown immediately.
