Recently Viewed Records

One click to jump back to any record you opened — across all models.

Overview

Every time you open a form view in Odoo, this module quietly records it. A history icon appears in the top navigation bar (systray). Click it to see a clean dropdown listing the last 20 records you visited, with the model name and record title. Click any entry to navigate straight back to that record.

History is stored per user on the server, so it follows you across browsers and devices. No configuration needed — install and it works immediately.

Key Features

  • Tracks the last 20 records opened per user, across every model in Odoo.
  • Systray history icon — always one click away, never in the way.
  • Upsert logic: re-opening the same record moves it to the top rather than creating a duplicate.
  • Server-side storage — history persists across devices and browser sessions.
  • Each user sees only their own history; complete access isolation enforced via Odoo record rules.
  • Graceful handling of deleted records — shows the stored name rather than breaking.
  • Zero performance impact: fire-and-forget async logging, pruning on insert, indexed queries.

How It Works

  1. Install the module.
  2. Open any record anywhere in Odoo.
  3. Click the history icon (⏳) in the top-right systray bar.
  4. Your recently opened records appear in a dropdown — click any to return to it instantly.

Technical Information

  • Compatible with Odoo 19.0
  • Dependencies: web
  • License: LGPL-3
  • Adds one lightweight table: ir.recent.record (max 20 rows per user)
