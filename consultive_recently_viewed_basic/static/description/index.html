Jump Back to Any Record.
One Click.

Every time you open a form view in Odoo, this module quietly logs it. A history icon appears in the top navigation bar — always one click away. Click it to see your last 20 visited records across every model, and click any entry to go straight back. History follows you across browsers and devices, no configuration required.

Everything You Need in One Module

🕐
One-Click Navigation
A systray history icon puts your last 20 visited records one click away, from anywhere in Odoo.
📱
Cross-Device History
History is stored server-side and follows you across browsers, tabs, and devices — no local state.
🔄
Smart Upsert Logic
Re-opening a record moves it to the top rather than creating a duplicate — list stays clean and relevant.
🔒
Per-User Isolation
Each user sees only their own history. Enforced via Odoo record rules — complete access isolation.
✅
Graceful Deleted Records
If a record is deleted, its stored name is shown rather than breaking the history list.
⚡
Zero Performance Impact
Fire-and-forget async logging. Pruning on insert. Indexed queries. Max 20 rows per user in the DB.

How It Works

1
Install the module
Install from the Apps menu. No settings to configure, no restart required — it starts logging immediately.
2
Open any record
Navigate to any form view anywhere in Odoo. The module quietly logs it in the background with no delay.
3
Click the history icon
The ⏳ icon in the top-right systray opens a dropdown of your last 20 visited records — model name and title shown for each.
4
Click any entry to navigate back
One click on any history entry returns you directly to that record — no searching, no breadcrumbs, no hunting.
