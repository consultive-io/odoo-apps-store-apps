Smart Watermark PDF

State-aware diagonal watermark on every PDF report — fully configurable per model via Settings, zero code changes needed.

Overview

Smart Watermark PDF automatically overlays a bold diagonal watermark on every PDF or printed report whenever the underlying Odoo record is in a non-confirmed state — for example, a draft Sale Order, a Request for Quotation, or an invoice in draft. The watermark label and the states that trigger it are fully configurable per model through a simple Settings UI, with no code changes required.

Key Features

  • State-aware: watermark appears only on records in non-confirmed states — confirmed PDFs are clean.
  • Fully configurable per model via Settings > Technical > Reporting > Watermark Configuration.
  • One-click “Load States from Model” auto-populates every state value with a sensible default label.
  • Covers all four built-in Odoo report layouts: Standard, Striped, Boxed, and Bold.
  • Compatible with both Odoo Community and Enterprise editions.
  • Multi-company aware — company-specific configuration overrides global configuration.
  • Safe opt-in: a model with no configuration gets no watermark.
  • States added after “Load States” auto-generate a label from the state value — nothing breaks.
  • Lightweight — depends only on the core web module.

How It Works

  1. Create a configuration — go to Settings > Technical > Reporting > Watermark Configuration and add any Odoo model that has a Print PDF action (e.g. Sale Order, Invoice, Purchase Order).
  2. Load states — click “Load States from Model” to auto-populate every state value with its default label.
  3. Mark confirmed states — tick “Confirmed (No Watermark)” for the states that should not show a watermark (e.g. sale and done for Sale Orders).
  4. Print — draft PDFs now carry a diagonal watermark; confirmed PDFs are clean.

Technical Information

  • Compatible with Odoo 19.0

  • Dependencies: web (no additional modules required)
